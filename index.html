      How to generate a trace
      

        

          
Python fully automatic

          
Put dsaviz.py next to your script, then:


from dsaviz import trace

def bubble(a):
    for i in range(len(a)):
        for j in range(len(a) - i - 1):
            if a[j] > a[j+1]:
                a[j], a[j+1] = a[j+1], a[j]
    return a

trace(bubble, [5, 3, 8, 4, 2])          # writes trace.json

          
Every line executed is captured automatically via sys.settrace — locals, call stack, and depth. Lists render as bars, 2-D lists as DP tables, node objects as trees or linked lists.

        

        

          
Java explicit snapshots

          
Put DsaViz.java in your folder, then:


static void bubble(int[] a) {
  for (int i = 0; i < a.length; i++)
    for (int j = 0; j < a.length-i-1; j++) {
      DsaViz.watch("a", a).watch("i", i).watch("j", j);
      DsaViz.step(4, "compare " + a[j] + " vs " + a[j+1]);
      if (a[j] > a[j+1]) { int t=a[j]; a[j]=a[j+1]; a[j+1]=t; }
    }
}

public static void main(String[] x) {
  DsaViz.begin("Bubble.java");
  bubble(new int[]{5,3,8,4,2});
  DsaViz.save("trace.json");
}

          
Java has no portable line-hook, so you mark the interesting moments yourself. One step() call per frame.
